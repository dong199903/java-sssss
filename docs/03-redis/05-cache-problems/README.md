# 05 缓存三大问题与一致性

[← 上一知识点](../04-persist-ha/README.md) | [Redis 集合](../README.md) | [下一知识点 →](../06-dist-lock/README.md)

## 讲解

- **穿透**：查不存在的，打到 DB → Bloom 或空值短 TTL  
- **击穿**：热点 key 过期瞬间 → 互斥重建或逻辑过期  
- **雪崩**：同时失效或 Redis 挂 → TTL 随机、高可用、限流  

一致性：没有绝对强一致。**Cache Aside：先更 DB，再删缓存**；失败用消息重试。先改缓存再改库，库失败会留下脏数据。
