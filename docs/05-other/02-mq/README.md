## 讲解

用 MQ 换：解耦、异步、削峰。付出：最终一致、重复、乱序、堆积、运维。

共性三问：**不丢、不重、有序**。

- 不丢：生产确认 + Broker 副本 + 消费手动提交  
- 不重：业务幂等（唯一键、状态机）  
- 有序：同分区单线程，全局有序会牺牲并行  

推实时难反压，拉好控速。Kafka 长轮询拉。堆积先看生产过快还是消费 hang。

Rabbit：TTL+死信做延迟；拒绝/过期/队列满进 DLX。  
RocketMQ：NameServer 无状态；事务消息半消息+回查。  
Kafka：旧架构 ZK 管元数据，KRaft 去掉 ZK；事务是生产侧 EOS。
