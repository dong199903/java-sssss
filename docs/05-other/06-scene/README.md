## 讲解

场景题按 **流量路径 → 瓶颈 → 一致性** 答。

- **限流**：固定/滑动窗口、漏桶、令牌桶。令牌桶允许突发。  
- **秒杀**：前端+网关限流，Redis 原子扣库存，异步下单，防超卖对账。  
- **分布式 ID**：号段、雪花（时钟）、Redis INCR。主键要趋势递增。  
- **短链**：发号 62 进制，302，缓存，唯一索引。  
- **点赞**：Set 去重 + 计数，异步落库。  
- **RPC 框架**：协议、序列化、发现、负载、超时、线程模型。  
- **CPU 飙高**：top → 线程 → jstack/火焰图；也要怀疑 GC。

锁见 Redis 06；MySQL 深度分页见 MySQL 08。
