## 分析结论（先看这个）

1. **Java 热门 200** 偏「原理深挖」；这六本把 **语言基本功** 和 **每个中间件的边角** 补齐了。  
2. 集合/并发很多题是已有 Demo 的变体，不新开目录，只往文末「对应题目」加题。  
3. 真正缺、而且能跑通的新点：equals 契约、传值、String/装箱、异常、泛型擦除、序列化、反射 SPI、类加载、Java8、COW、CountDownLatch/CF、redo/undo/binlog、Bloom/HLL、FactoryBean、自调用失效。  
4. 注解百科（`@PathVariable` 一类）不单独成章，挂在 MVC 对应题目里。

每题对应哪个知识点，看各分类 README 的「对应题目」。
